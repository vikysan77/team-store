# Inter Store

Inter Store is a web application developed with TypeScript and Vite.

## Tech Stack

- Vite
- TypeScript
- ESLint
- Prettier
- Vitest

## Deployment

The store is published on GitHub Pages: https://vikysan77.github.io/team-store/

## Getting Started

Install dependencies:

```bash
npm ci
```

Start the development server:

```bash
npm run dev
```

## Production Build

```bash
npm run build
```

## Testing

```bash
npm test
```

## Code Quality

Run ESLint:

```bash
npx eslint .
```

Check formatting:

```bash
npx prettier --check .
```
